# cyberia-mc
💌Сайт-визитка для ванильного Minecraft-сервера Cyberia.

Я плохо разбираюсь в программировании, а также верстке сайтов, но нужно было удобное место, куда заинтересованный человек может зайти, ознакомиться с сервером, прочитать правила с FAQ и сразу найти ссылки на наш Discord.
Дизайн и код собирал с помощью ИИ (Gemini). Я придумывал идеи, структуру и дизайн, а нейросеть помогала всё это сверстать на HTML, CSS и JS.
